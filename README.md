# VELORA Wellness

A responsive premium botanical skincare storefront concept built with React and Vite. The site includes a responsive navigation menu, product cards, a working demo shopping bag with quantity controls, FAQ accordion, newsletter interaction, and motion-reduced styles.

## Run locally

Install Node.js, open this folder in VS Code, then run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite.

## Production build

```powershell
npm.cmd run build
npm.cmd run preview
```

## Before publishing

- VELORA is a fictional portfolio concept. Check brand-name availability before using it commercially.
- Product copy, prices, and ingredient statements are illustrative. The site does not make medical claims.
- The shopping bag is a front-end demo. Checkout, inventory, payments, and email subscriptions are not connected to a backend.
- Product photography and web fonts are loaded from external providers and require an internet connection.
- Replace `hello@velora.example` with a contact address you control.
